# Research companion instructions

This repository is an unpublished release candidate. Do not infer release approval from passing checks. Preserve source pins, recorded outputs, protocols and negative results. Original archive package files are sealed by their nested manifest; adapt via separately documented revisions rather than editing those files silently.

Default verification is `python3 -B verify.py`. Full reproduction instructions are in README.md. No paid inference, live-target testing or execution of historical payloads is part of this project. Generated raw runs and downloaded source belong in ignored directories. Before publishing a change, inspect exact tracked contents, provenance, qualifications and link integrity. AI review is not independent human review.
