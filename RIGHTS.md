# Rights, attribution and publication boundary

MIT was selected for Fide-authored code, prose, figures and derived release material, consistent with existing Fide investigation repositories. This preparation does not make the repository public or authorize website publication. Human scientific/editorial review and the exact coordinated release decision remain pending.

AgentDojo's pinned root license is MIT, with its original author names retained verbatim in LICENSES/AgentDojo-MIT.txt and archive/UPSTREAM-LICENSE.txt. The existing correction is upstream work. Fide analysis scripts call or adapt benchmark predicates; this notice applies to any such included upstream-derived material. The included UserTask13 diff is attributed to that pinned source under that notice.

No upstream implementation checkout, raw trace corpus, complete third-party paper, or dependency distribution is bundled. Derivative numeric/Boolean projections and source hashes retain provenance without reproducing raw messages. Prompt and goal strings in compatibility observations are represented by hashes. User-authored runtime outputs can include such strings and local paths and are ignored by Git.

Dependencies and acquired sources are obtained by the reader under their own terms. A dependency license inventory records metadata as supplied by installed distributions; metadata can be incomplete and is not legal clearance. Dependency versions are pinned, not wheel-file hashes, and cross-platform behavior is unqualified.

The archive subpackage remains byte-identical for reproducibility. Its historical RIGHTS.md and QUALIFICATION.json describe the earlier private stage; this root document and LICENSE state the current prepared repository policy without rewriting old evidence.

Automated scans can detect known patterns, not prove the absence of every secret or sensitive datum. The release manifest is an explicit content inventory, not a signature or guarantee of authenticity.
